# NetSentinel
Python-based CLI tool for network reconnaissance, Nmap automation and security reporting. Work in progress.

Sobre o projeto

O NetSentinel é uma ferramenta CLI (Command Line Interface) desenvolvida em Python, com foco em reconhecimento de redes e automação de tarefas utilizadas durante testes de penetração.

O projeto nasceu durante meus estudos de Cybersecurity, redes de computadores e Pentest, com o objetivo de aplicar meus conhecimentos de Python e Nmap na construção de uma ferramenta própria.

O NetSentinel está em desenvolvimento e será aprimorado conforme minha evolução técnica.

⚙️ Funcionalidades

Implementadas

Interface CLI em Python.

Banner ASCII personalizado.

Reconhecimento de argumentos pelo terminal.

Modos de execução -scan e -ftv.

Validação de endereços IPv4 e IPv6.

Tratamento básico de erros.
